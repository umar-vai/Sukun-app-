# Sukun font assets

Li Ador Noirrit is a supplied/licensed brand font, **not** a Google Font.

Original binary .ttf files must be added only with approval for use and redistribution in the public Web bundle. Do not commit placeholder/renamed fallback fonts as if they were Li Ador Noirrit.

See `docs/qa/LI_ADOR_NOIRRIT_FONT_ONBOARDING_20261023.md` for exact filenames, ten weight/style mappings, Flutter registration, and release checks.

The font selector safely disables Li Ador Noirrit until `SUKUN_LI_ADOR_NOIRRIT_BUNDLED=true` is set after all ten real files have been bundled. Scripture Arabic typefaces remain unchanged.
