# Sukun Life bundled Bengali brand font

The user confirmed permission to embed and distribute **Li Ador Noirrit** in the Sukun Life web and mobile application.

The ten original TTF faces are bundled under `assets/fonts/li_ador_noirrit/`, unchanged, and registered in `app/pubspec.yaml` as Flutter family `SukunLiAdorNoirrit` (weights 200, 300, 400, 600, 700, with italic variants).

Do not replace these files with similarly named font downloads or expose them as standalone downloadable assets. They are application resources only.

Font Selection is enabled by default. For incident rollback of the picker only, build with `--dart-define=SUKUN_LI_ADOR_NOIRRIT_BUNDLED=false` (fonts remain bundled in this build). Keep Arabic Quran typography unchanged.

See `docs/qa/LI_ADOR_NOIRRIT_FONT_ONBOARDING_20261023.md` for the weight map and QA requirements.
